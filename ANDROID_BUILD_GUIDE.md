# New Kerala Chips Android

Prepared for Capacitor Android. Install Node.js and Android Studio, then run:

```bash
npm install
npm run build
npx cap add android
npx cap sync android
npx cap open android
```

Then use Android Studio to run the app or generate an APK.

App ID: com.newkeralachips.billing
App name: New Kerala Chips Billing

Barcode and thermal-printer native integrations still need plugin/hardware implementation and testing.
